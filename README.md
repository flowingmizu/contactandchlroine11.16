# Mizuverse Labs · Chlorine Pathway (1.0 beta)

Practise the plant before you run the plant.

A browser-based virtual lab for water-treatment students. One app, two connected modules:

1. **Chlorine Demand** – add chlorine, run DPD tests, and discover the breakpoint curve (zones, demand, combined vs. free chlorine).
2. **Contact Time** – tracer/T10 and baffling concepts, CT calculations, and how contact time affects disinfection.

## How each scenario flows

Pre-quiz → Lab → Critical thinking (with math from your own lab numbers) → Bridge question to the next scenario.

Includes "Build the curve" and "Curve viewer" tools, a chlorine stock budget, exam-prep questions, a progress tracker, a "My results" page, and an instructor view.
